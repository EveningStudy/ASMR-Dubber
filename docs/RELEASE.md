# ASMR Dubber 1.4.0

## 主要更新

- IndexTTS-2.5 独立后端、固定模型包、修复回滚和额外生成参数。
- 多模型复核改为共同音频片段，默认仅建议，支持试听、采纳、确认、撤销和缓存重试；不依赖 LLM。
- 设置保存范围分为默认值、当前项目、两者；修复 TTS 保存后刷新显示启动时旧值。
- 修复大句子表渲染卡顿、Whisper 进度反馈、Parakeet 单片段错误扩散。
- 完整分轨字幕不因语言不同回退整段 ASR；修复中文译名中“・”导致的语言误判。
- 加强缓存完整性、稳定重试种子、跨域音频凭证隔离、项目冲突保护、失败恢复。
- 发布增加测试门槛和核心 wheel 依赖清单；补图文教程与文档索引。

## 下载与启动

Windows 下载本 Release 的 `ASMR-Dubber-windows-portable-v1.4.0.zip`，完整解压后运行 `ASMR-Dubber-Setup.exe`，再运行 `ASMR-Dubber.exe`。

Linux x86_64 下载源码包，在根目录执行：

```bash
bash scripts/linux/setup.sh 推荐
bash scripts/linux/run-ui.sh
```

IndexTTS-2.5 从“设置 → 设备与模型”按需安装，不属于默认安装方案。多模型音频片段复核为实验性功能，效果可能不如单模型，默认只提出建议。

## 升级

先停止任务并备份项目、配置和已有成品，再完整覆盖程序文件，保留 `.asmr-dubber` 及外部项目目录。运行 Setup 检查运行环境，然后重新启动程序；只刷新网页不会加载新的程序代码。

已有复核记录可通过“只重试音频复核”重新生成。需要重做批量成品时，先核对每轨字幕与语言，再明确选择重做，避免覆盖未备份结果。

安装和操作说明见[安装指南](INSTALLATION.md)、[使用指南](USER_GUIDE.md)及[图文复核教程](AUDIO_REVIEW_TUTORIAL.md)。
